Data are presented as events/patients and risk ratios (RRs) with 95% confidence intervals (CIs), with C1 as the reference within each stratum. RRs were estimated using modified Poisson regression adjusted for Model 3 covariates. Interaction P values test the interaction between trajectory class and subgroup. FDR q values were calculated using the Benjamini–Hochberg procedure across nine interaction tests. MAKE30 analyses excluded 46 MIMIC-IV, 130 eICU-CRD and 196 SICdb patients without evaluable MAKE30 outcomes, leaving 9,758, 5,709 and 3,635 patients, respectively.
