# Private inputs

Keep every input and generated output in an authorised private workspace outside the repository. The `.gitignore` is an additional protection, not a substitute for this separation.

## Standalone covariate SQL

Run `01_SQL/00_create_private_input_tables.sql` to create empty tables in the **private** database. Populate the relevant table from locally generated cohort/classification records before running a public query:

| Local relation | Query |
| --- | --- |
| `local_inputs.mimic_baseline_seed` | MIMIC standalone covariate extraction |
| `local_inputs.eicu_baseline_seed` | eICU standalone covariate extraction |
| `local_inputs.sicdb_baseline_seed` | SICdb standalone covariate extraction |
| `local_inputs.sicdb_vitals_seed` | SICdb respiratory-rate and temperature extraction |
| `local_inputs.eicu_cci_seed` | eICU Charlson diagnosis/history extraction |
| `local_inputs.eicu_survival_review_ids` | Targeted review of eICU hospital-status records |

The first three tables contain `unit_id`, `hospital_id`, `patient_id`, `onset_timestamp`, `onset_offset`, `assigned_class` and `frozen_baseline` (a JSONB copy of the local frozen baseline row). Use the same database-specific identifier and time convention as the original cohort extraction. SICdb vitals use onset offsets in seconds. The complete column definitions are in the schema SQL and `PRIVATE_INPUT_SCHEMAS.json`. No example patient records are distributed.

The SQL scripts still contain database item IDs, reference codes, antibiotic patterns and diagnostic mappings. Those are extraction definitions, not embedded patient records.

## Survival adjudications

The public survival-preparation and baseline-aggregation scripts read a private `sicdb_adjudications.csv`, specified by `MSI_SICDB_ADJUDICATIONS` or located at `private_inputs/sicdb_adjudications.csv` under the private project root.

Required columns:

```text
case_id,death_override,discharge_override,ignore_negative_discharge_day
```

The three flags are binary integers. The study's existing count checks require 12 death overrides, 6 discharge-related overrides and one negative-discharge-day override. The public code retains the original handling of each flag; it does not create replacement adjudications. Obtain the study-specific records through the author team subject to database access rules. Missing local adjudications stop execution rather than silently altering the analysis.

## Other local inputs

- Original cohort CSV exports and frozen classifications generated by the trajectory stages.
- Local RDS inputs and scoring states generated during modelling; these are not distributed because they may contain patient-level information.
- Covariate exports and field dictionaries used by Table 1 and adjusted regressions.
- Completed local MICE objects required by the subgroup and sensitivity analyses.
- Survival exports and same-hospital review data required by the existing endpoint rules.
- Locally produced summary tables for presentation scripts, and Word layout templates where a historical formatter reads an existing document.

No database credentials are stored in this repository. Execute extraction only in a database where the required native schemas are available. The full extraction scripts create study schemas and tables; inspect their object names before execution.
